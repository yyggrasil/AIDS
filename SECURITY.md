# Política de Segurança

## Reportando Vulnerabilidades

A segurança deste projeto é levada a sério. Se você descobrir uma vulnerabilidade de segurança, siga as orientações abaixo:

1. **Não abra uma Issue pública** para reportar vulnerabilidades de segurança.
2. Envie um e-mail com os detalhes da vulnerabilidade para o mantenedor do repositório ou utilize o recurso de **Security Advisory Privado** do GitHub no repositório.
3. Descreva:
   - Tipo de vulnerabilidade.
   - Passos para reprodução ou Proof of Concept (PoC).
   - Impacto potencial no sistema.

Agradecemos pelo esforço em tornar este projeto mais seguro!
